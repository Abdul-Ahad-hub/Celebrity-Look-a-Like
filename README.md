A project based on CV and AI.
A Flask-based web application that identifies celebrities in uploaded images. The app uses face recognition to compare uploaded faces with a pre-built dataset of celebrity images.
Celebrity images were collected using a web crawler, scraping the internet, and their face encodings are stored for fast matching.
Python 3.10+
Flask → Web framework
face_recognition → Face detection & encoding (built on dlib)
NumPy → Similarity calculations
Werkzeug → Secure file handling
Pickle → Storing face encodings
HTML (Jinja templates) → Frontend
Custom Web Crawler → Collected celebrity dataset
